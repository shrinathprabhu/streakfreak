# Geist Sans

`GeistVariable.woff2` is the unmodified variable Geist Sans font (weights 100–900) from Vercel’s [Geist v1.7.2 release](https://github.com/vercel/geist-font/releases/tag/v1.7.2).

Original archive path: `geist-font/Geist/webfonts/Geist[wght].woff2`.

The original SIL Open Font License is distributed at `public/fonts/OFL-Geist.txt` and included in the static site. The layout uses `next/font/local` to emit a hashed, preloaded font asset and a shared CSS variable. The PWA includes the font in its offline cache. No font provider is contacted at runtime or during subsequent builds.
